# Acme Demo

Acme-specific screens built from the generic [`ui-library`](../ui-library/) components.

## Screens

- `gallery.crepus` — photo grid using `Grid`
- `file-browser.crepus` — file list using `List`
- `settings.crepus` — grouped settings using `Panel`
- `pairing.crepus` — device pairing flow using `Wizard`

These demos are rendered with `crepus render` and are targets for `crepus web`, `crepus gpui`, and `crepus native`.
